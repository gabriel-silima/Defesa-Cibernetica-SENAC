# Guia de publicação — SENAC / Defesa Cibernética

## Conta de destino

**Somente** `github.com/gabriel-silima` para este projeto. O repositório central é `gabriel-silima/Defesa-Cibernetica-SENAC`.

## Checklist antes de cada publicação

- [ ] O `remote` local aponta para `gabriel-silima`, não para `gsilveiralima`.
- [ ] A identidade autenticada no GitHub CLI foi verificada (quando aplicável).
- [ ] O material é próprio ou pode ser redistribuído.
- [ ] Não há senhas, tokens, dados pessoais reais ou topologias internas.
- [ ] Os resultados e screenshots correspondem a testes efetivamente executados.
- [ ] Cada atividade informa data, ambiente, comandos, observações e limitações.
- [ ] O README contém objetivo, pré-requisitos e procedimento de reprodução.
- [ ] Foram documentadas medidas preventivas, defensivas ou corretivas.

## Modelo mínimo de registro

```markdown
# Nome do laboratório

- Objetivo:

- Diagnóstico / mitigação:
- Pendências:
```

## Organização e avaliação

Não considerar uma atividade concluída somente porque seu roteiro ou repositório foi criado. Comprovação requer resultado observado e evidência verificável. Preservar o material original do professor fora do repositório público, salvo autorização expressa.
