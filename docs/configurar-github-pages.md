# Como disponibilizar o portfólio em GitHub Pages

O arquivo `index.html` na raiz da branch `main` foi preparado como página estática responsiva, sem dependências externas.

## Publicação

1. Abrir o repositório `gabriel-silima/Defesa-Cibernetica-SENAC` na conta SENAC.
2. Ir a **Settings → Pages**.
3. Na seção de origem de publicação, selecionar **Deploy from a branch**, se esta opção estiver disponível.
4. Selecionar **main** e a pasta **/(root)**, e salvar.
5. Depois de o GitHub concluir o deploy, verificar a URL informada pela própria página de configurações (o endereço provável é `https://gabriel-silima.github.io/Defesa-Cibernetica-SENAC/`, mas deve ser confirmado após a ativação).

**Situação atual:** o arquivo de portfólio foi disponibilizado no repositório, mas a ativação do GitHub Pages depende das configurações da conta e não foi confirmada por esta documentação.

## Verificações recomendadas

- Verificar se o HTML carrega e se o layout funciona em celular.
- Abrir todos os links de laboratórios e projetos.
- Conferir que nenhuma credencial ou informação pessoal real foi publicada.
- Não marcar como concluída uma atividade que ainda aguarda execução ou evidência.
